# Логічна схема БД ієрархічної моделі даних

У цій схемі кореневим вузлом є **Пацієнт**, який має власну медичну картку (**МедичнаКартка**),  
а записи (**МедичнийЗапис**) створюються лікарем (**Лікар**).

```mermaid
graph TD
    Пацієнт(Пацієнт)
    Пацієнт --> ПІБ((ПІБ))
    Пацієнт --> датаНародження((датаНародження))
    Пацієнт --> зріст((зріст))
    Пацієнт --> вага((вага))
    Пацієнт --> МедичнаКартка(МедичнаКартка)
    МедичнаКартка --> номерКартки((номерКартки))
    МедичнаКартка --> датаСтворення((датаСтворення))
    МедичнаКартка --> МедичнийЗапис(МедичнийЗапис)
    МедичнийЗапис --> дата((дата))
    МедичнийЗапис --> типЗапису((типЗапису))
    МедичнийЗапис --> опис((опис))
    МедичнийЗапис --> Лікар(Лікар)
    Лікар --> ПІБ_лікаря((ПІБ))
    Лікар --> спеціалізація((спеціалізація))
