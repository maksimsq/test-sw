### 1.3.2-Glossary
### Глосарій термінів

| № | Термін | Визначення / Пояснення |
|---|---|---|
| 1 | **AR-Marker (ArUco)** | Синтетичний квадратний маркер із чорною рамкою та внутрішньою бінарною матрицею, що використовується для комп'ютерного зору. |
| 2 | **Матеріальний контролер** | Фізичний елемент керування (у нашому випадку — лінійний повзунок), оснащений AR-маркером для взаємодії з системою. |
| 3 | **PL / BL / AL** | Рівні архітектури програмного продукту: Presentation Layer (представлення), Business Logic (бізнес-логіка), Access Layer (доступ до даних). |
