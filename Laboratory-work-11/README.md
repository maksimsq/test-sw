## Керування процесами-транзакціями в базах даних

### 2.1 Теоретичне завдання зі створення історій виконання транзакцій
Завдання: 2.1.1 Створити історію квазіпаралельного успішного виконання транзакцій для протоколу 1-го ступеня блокування.
Приклад формату опису історії: H(T1,T2) = O11, O21, O12 ...

Транзакції:
- T1 = R1[A], W1[A], C1
- T2 = W2[A], R2[B], W2[B], C2
- T3 = R3[D], R3[B], W3[D], C3

Опис операцій:
- R[X] — читання значення змінної X
- W[X] — запис нового значення в змінну X
- C — операція завершення транзакції (COMMIT)

Історія виконання транзакцій для протоколу 1-го ступеня блокування:

H(T1,T2,T3) = 
    X1[A] R1[A] X1[A] W1[A] X2[A] W2[A] X2[B] R2[B] W2[B] 
    X3[D] R3[D] X3[B] R3[B] X3[D]-Wait 
    C1 U1 
    X3[D] W3[D] 
    C2 U2 
    C3 U3

Завдання 2.1.2 Під час опису історії описати таблицю блокування транзакцій до моменту першої фіксації змін однієї з транзакцій у вигляді масиву на мові програмування С, наприклад, використовуючи масив char* lock_table.
Таблиця блокування транзакцій до моменту першої фіксації (тобто до C1):

H(T1,T2,T3) = 
    X1[A] R1[A] X1[A] W1[A] X2[A] W2[A] X2[B] R2[B] W2[B] 
    X3[D] R3[D] X3[B] R3[B] X3[D]-Wait


char* lock_table[][3] = {
    { "A", "X1", "X2" },
    { "B", "X2", "X3" },
    { "D", "X3", "-" }
};

Завдання: 2.1.3 Для створеної історії з попереднього завдання визначити наявність Deadlock- стану транзакцій, створивши граф очікування транзакцій, та зробити відповідний висновок. Представити граф у вигляді масиву на мові програмування С, наприклад, використовуючи масив int wait.

Граф очікування транзакцій:
int wait[1][2] = { {3, 1} };

Висновок: На основі побудованого графа очікування транзакцій встановлено, що він не містить циклів, отже, Deadlock-стан транзакцій відсутній.

Завдання 2.1.4 Повторити завдання 2.1.1, але для протоколу 2-го ступеня блокування.

Транзакції:
- T1 = R1[A], W1[A], C1
- T2 = W2[A], R2[B], W2[B], C2
- T3 = R3[D], R3[B], W3[D], C3

Історія виконання транзакцій для протоколу 2-го ступеня блокування:

H(T1,T2,T3) = 
    X2[A] W2[A] X2[B] R2[B] W2[B] 
    X1[A] R1[A] W1[A] 
    X3[D] R3[D] 
    X3[B] R3[B] 
    X3[D]-Wait 
    C2 U2 
    C1 U1 
    X3[D] W3[D] 
    C3 U3


Завдання 2.1.5 Для створеної історії з попереднього завдання визначити наявність Deadlock-стану транзакції, створивши граф очікування транзакцій, та зробити відповідник висновок. Представити граф у вигляді масиву на мові програмування С.

Граф очікування транзакцій:
int wait[1][2] = { {3, 1} };


Висновок: У графі очікування транзакцій немає циклів, отже, Deadlock-стан транзакцій відсутній.
