### 2.5-DataLinter
### Перевірка норм кодування (Data Linter)

У цьому каталозі зафіксовано результати експериментів з перевірки SQL-скрипта фізичної схеми за допомогою лінтера `sqlfluff`:
* **DataSchemaCodeConventionResult.jpg** — результат перевірки коректної схеми даних на відповідність стандартам форматування та синтаксису.
* **DataSchemaModified** — модифікована версія схеми з навмисно порушеними нормами кодування (або синтаксичними відхиленнями) для експерименту.
* **DataSchemaModifiedCodeConventionResult.jpg** — результат перевірки помилок для зміненої схеми даних.
