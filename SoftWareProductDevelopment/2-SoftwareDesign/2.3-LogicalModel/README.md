### 2.3-LogicalModel
### Логічна схема БД (Реляційна модель)

Логічна модель даних проєкту **SliderAR** побудована на основі реляційного підходу та складається з п'яти взаємопов'язаних таблиць, що відповідають концептуальним класам системи:

1. **Camera** — зберігає параметри джерела відеопотоку.
2. **ArUcoMarker** — містить дані про оптичні маркери та посилається на камеру (`cameraId`).
3. **SliderController** — описує стан матеріального контролера (повзунка), пов'язаний із маркером (`markerId`).
4. **Calibration** — зберігає параметри калібрування робочого діапазону слайдера (`sliderId`).
5. **SystemConfig** — містить профіль конфігурації системи та статус готовності, пов'язаний із калібруванням (`calibrationId`).

Графічне представлення логічної реляційної схеми зафіксовано у файлі `RelLogicalSchema.puml`.
