### 2.4-PhysicalSchema
### Фізична схема бази даних (SQL)

У цьому каталозі міститься SQL-скрипт (`DataSchema.sql`) для створення реляційної бази даних системи **SliderAR**.

**Особливості фізичної схеми:**
* Реалізовано повний набір таблиць: `Camera`, `ArUcoMarker`, `SliderController`, `Calibration`, `SystemConfig`.
* Використано типи даних (`INT`, `VARCHAR`, `FLOAT`, `DATE`) відповідно до СУБД.
* Налаштовано первинні (`PRIMARY KEY`) та зовнішні (`FOREIGN KEY`) ключі з каскадним видаленням.
* Використано обмеження `CHECK` для перевірки діапазонів значень та станів.
* **Застосовано регулярні вирази (REGEX) через оператор `CHECK (~ ...)`:**
  1. Для таблиці `Camera` (атрибут `resolution`) — перевірка формату роздільної здатності (наприклад, `1920x1080`).
  2. Для таблиці `SystemConfig` (атрибут `configName`) — перевірка допустимих символів у назві конфігурації (лише латинські літери, цифри, пробіли, підкреслення та дефіси).
