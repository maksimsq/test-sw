### 1.3.5-OtherNFR
### Опис основних нефункціональних вимог

#### 1. Вимоги до продуктивності (Time Performance)
| ID | Параметр | Вимога до часу / швидкодії |
|---|---|---|
| NFR-PF-1 | Затримка обробки кадру | Час обробки одного кадру відеопотоку алгоритмом ArUco не повинен перевищувати 33 мс (не менше 30 FPS). |
| NFR-PF-2 | Реакція на зміну положення | Оновлення інтерфейсу при зміні положення повзунка має відбуватися із затримкою не більше 50 мс. |

#### 2. Вимоги до інтерфейсу із зовнішніми пристроями
| ID | Зовнішній пристрій | Вимога |
|---|---|---|
| NFR-DEV-1 | Веб-камера / Камера смартфона | Підтримка роздільної здатності не нижче 720p (HD) із частотою від 30 кадрів/с для стабільного розпізнавання маркера. |
| NFR-DEV-2 | Фізичний повзунок | Наявність чітко наклеєного контрастного ArUco-маркера розміром не менше 3х3 см для надійного трекінгу. |

#### 3. Вимоги до програмного інтерфейсу (API)
| ID | Інтерфейс | Опис |
|---|---|---|
| NFR-API-1 | OpenCV / ArUco API | Використання бібліотеки для обробки графічних масивів та детекції маркерів. |

#### 4. Вимоги до інтерфейсу передачі даних
| ID | Тип передачі | Опис |
|---|---|---|
| NFR-DATA-1 | Локальний потік даних | Передача координат і розрахованих значень у форматі JSON у межах оперативної пам'яті застосунку. |
