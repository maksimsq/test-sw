### 1.3.1-FR
### Опис функціональних вимог

Дворівневий опис функціональних вимог сформовано на основі BDD-специфікацій рішення Лабораторної роботи №1.

| ID вимоги | Назва вимоги | Опис (User Story аналіз) |
|---|---|---|
| **FR1** | **Визначення положення фізичного повзунка** | **Аналіз BDD-специфікації №1** |
| FR1.1 | Захоплення відеопотоку та детекція ArUco-маркера | Система повинна отримувати кадри з камери та виявляти ArUco-маркер на фізичному повзунку (аналіз «I want to»). |
| FR1.2 | Розрахунок геометричних координат | Система повинна обчислювати поточні координати маркера у просторі кадру (аналіз «I want to»). |
| FR1.3 | Відображення стану матеріального контролера | Система повинна візуалізувати розраховане положення повзунка на екрані, щоб користувач розумів поточний стан матеріального контролера (аналіз «In order to»). |
| **FR2** | **Калібрування робочого діапазону слайдера** | **Аналіз BDD-специфікації №2** |
| FR2.1 | Фіксація початкової та кінцевої точок | Система повинна дозволяти користувачеві фіксувати крайні положення (мінімум та максимум) слайдера (аналіз «I want to»). |
| FR2.2 | Збереження параметрів калібрування | Система повинна зберігати налаштовані межі робочої області слайдера у конфігурації (аналіз «I want to»). |
| FR2.3 | Нормалізація значень у робочому діапазоні | Система повинна приводити поточні координати повзунка до відповідного робочого діапазону (0–100%) для подальшого використання (аналіз «In order to»). |
