### 1.3.2-Glossary
### Глосарій термінів

| Термін / Скорочення | Визначення / Пояснення |
|---|---|
| **ArUco-маркер** | Синтетичний квадратний двомірний штрих-код із чорною рамкою та внутрішньою бінарною матрицею, який використовується для точного позиціонування об'єктів у комп'ютерному зорі. |
| **Матеріальний контролер (повзунок)** | Фізичний елемент керування (слайдер), на якому закріплено ArUco-маркер для безконтактного відстеження його положення камерою. |
| **Робочий діапазон** | Інтервал між мінімальним (початковим) та максимальним (кінцевим) фізичним положенням повзунка, відкалібрований для інтерпретації значень у відсотках (0–100%). |
| **Калібрування слайдера** | Процес програмного задання та фіксації крайніх точок руху фізичного повзунка для точного обчислення його відносного положення. |
| **Візуальний трекінг** | Процес безперервного відстеження та обчислення координат маркера на відеокадрах у режимі реального часу. |
