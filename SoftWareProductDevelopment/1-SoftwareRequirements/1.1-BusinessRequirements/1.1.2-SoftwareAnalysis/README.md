# Аналіз аналогів для SliderAR

## 1. OpenCV ArUco
- **Веб-ресурс:** https://docs.opencv.org/4.x/d5/dae/tutorial_aruco_detection.html
- **Властивості ПП:** бібліотека комп’ютерного зору з відкритим кодом; виявлення квадратних маркерів на кадрах з відеопотоку; точне отримання координат кутів та ідентифікаторів маркерів; оцінювання просторового положення (pose estimation) за наявності параметрів калібрування камери.
- **Апаратне забезпечення та матеріальні об’єкти:** веб-камера або камера смартфона, обчислювальний пристрій (ПК/смартфон), друкований на папері ArUco-маркер.
- **Відмінність від SliderAR:** OpenCV є низькорівневою універсальною бібліотекою для обробки зображень і виявлення маркерів, тоді як SliderAR є прикладом спеціалізованого програмного продукту для навчального налаштування обладнання з використанням лінійного фізичного повзунка.

## 2. MediaPipe Interactive Markers / Object Detection
- **Веб-ресурс:** https://developers.google.com/edge/mediapipe/solutions/vision/object_detector
- **Властивості ПП:** інструменти комп’ютерного зору для розпізнавання об’єктів у реальному часі; висока швидкість обробки кадрів на мобільних і десктопних пристроях; кросплатформність та готові пайплайни машинного навчання.
- **Апаратне забезпечення та матеріальні об’єкти:** камера мобільного пристрою або ПК, набір візуальних об’єктів чи маркерів у полі зору камери.
- **Відмінність від SliderAR:** MediaPipe орієнтований на загальне розпізнавання об'єктів або частин тіла за допомогою важких ML-моделей, тоді як SliderAR зосереджений на конкретному прикладному завданні — зчитуванні лінійного положення матеріального контролера (повзунка з паперовим маркером) для точного налаштування параметрів.

## 3. reacTIVision
- **Веб-ресурс:** https://reactivision.sourceforge.net/
- **Властивості ПП:** відкрите програмне забезпечення для відстеження фідуціальних маркерів (fiducial markers) і мультитач-об’єктів на поверхні; передача даних про координати, кути обертання та рух об'єктів у реальному часі через протокол TUIO.
- **Апаратне забезпечення та матеріальні об’єкти:** камера (часто розташована під прозорою поверхнею або спрямована зверху), спеціальні друковані чорно-білі символьні маркери на фізичних об'єктах (повзунках, ручках).
- **Відмінність від SliderAR:** reacTIVision створений переважно для досліджень у сфері tangible user interfaces (TUI) і вимагає специфічної інфраструктури (камери над столом або TUIO-клієнтів), тоді як SliderAR розрахований на використання звичайної веб-камери або камери смартфона та паперових AR-маркерів у навчальному сценарії.

## 4. Матриця систематизованого порівняння

| Властивість | OpenCV ArUco | MediaPipe Object Detector | reacTIVision | SliderAR (заплановано) |
|---|---|---|---|---|
| Підтримка паперових/фізичних маркерів | Так (ArUco / ChArUco) | Частково (залежить від моделі) | Так (фідуціальні маркери) | Так (AR-Marker) |
| Використання звичайної камери (ПК/Смартфон) | Так | Так | Вимагає налаштування світла/ракурсу | Так |
| Визначення лінійного положення повзунка | Потребує алгоритмічної доробки | Потребує налаштування | Так (через TUIO-протокол) | Вбудована цільова логіка |
| Інтерфейс для навчального налаштування обладнання | Ні (це бібліотека) | Ні (це бібліотека) | Частково (платформа для прототипів) | Так |
| Простота розгортання для кінцевого користувача | Середня (потребує навичок програмування) | Середня | Низька (потребує калібрування поверхні) | Висока (з орієнтацією на навчальний процес) |

## Висновок
Проведений аналіз існуючих рішень показав, що на ринку та в середовищі розробників існують потужні інструменти комп'ютерного зору (OpenCV ArUco, MediaPipe) та спеціалізовані платформи матеріальних інтерфейсів (reacTIVision). Проте вони є або низькорівневими бібліотеками, що вимагають написання значної кількості допоміжного коду, або вузькоспеціалізованими системами. Метою майбутнього продукту **SliderAR** є поєднання зручності роботи з паперовими AR-маркерами через камеру та спеціалізованого інтерфейсу для навчального налаштування обладнання за допомогою фізичного лінійного повзунка.

*Примітка: властивості наведено за офіційними описами продуктів і технічною документацією. SliderAR є проєктною концепцією.*
